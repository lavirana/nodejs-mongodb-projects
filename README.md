# Node.js & MongoDB Projects

This repository contains a collection of projects built using **Node.js and MongoDB**. It includes backend APIs and application projects created for learning and development practice.

## Projects

- **BLOG** – Blog application
- **CHAT-APP** – Real-time chat application
- **ECOMMERCE-APP-BACKEND-APIS** – E-commerce backend APIs
- **ECOMMERCE-FRONTEND** – E-commerce frontend
- **FOOD-APP** – Food application
- **IMAGE-UPLOAD** – Image upload functionality
- **MANAGE-USERS** – User management
- **MYCONTACTS-BACKEND** – Contact management backend
- **SHORT-URL** – URL shortener application
- **VOTING_APP** – Online voting application

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JavaScript
- REST APIs

## Purpose

The purpose of this repository is to practice backend development, API creation, database operations, and full-stack application development using Node.js and MongoDB.
